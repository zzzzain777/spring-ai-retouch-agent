# AI 修图 Agent：业务规则

本文件记录当前独立实现的行为契约。具体字段与错误码由 `server/` 控制器、服务和测试确认；评测约束见 `eval/datasets/agent-behavior-v1/RUBRIC.md`。新增规则不得静默改变冻结评测集的既有判定。

## 1. 身份、素材与会话

- 注册/登录后使用 httpOnly Cookie 中的 JWT；外部 API 在 Java 服务。素材、会话、计划、任务和进度流按当前用户隔离；未登录返回 401，访问其他用户资源按当前接口契约返回 404（`AuthAndAssetTests`、`SessionTests` 有断言）；例外是会话导出按上游语义，指定的素材不在该会话（含他人素材）时返回 422“素材不在该会话中”。
- 上传支持 JPEG、PNG、WEBP，大小和像素上限按 Java 素材校验；图片字节保存在 S3 兼容对象存储，PostgreSQL 记录所有者、对象键和元数据。客户端只能通过 Java 签发的短期 URL 读取。
- 会话保存画布文档、当前素材、修订号和最多 20 条编辑历史。新编辑截断重做分支；撤销/重做从历史恢复文档与修订号。
- 计划等待确认期间若画布修订号变化，确认返回 409，旧计划不能再作用于新画布。

## 2. Agent 规划与执行

1. 用户给出自然语言指令。Java 生成画布摘要，通过 Spring AI ChatClient 把 22 个已注册工具的名称、描述与 Schema 提供给真实 DeepSeek 规划模型。
2. 模型返回的 tool calls **只是提议**。`SpringAiPlanner` 关闭 `ToolCallingAdvisor` 自动注册，并给规划工具安装禁止实际调用的回调；规划阶段不得改图。
3. `PlanValidator` 校验工具名、参数、隐藏参数、依赖、环、步数上限 8；工具与手动 API 走同一 `ToolRegistry` 和参数校验。
4. 没有可执行计划时给出简短回复；单步计划可直接派发；多步计划落库为 `queued`，用户确认前派发数为 0。
5. 确认后 Java 按依赖调度就绪步骤。文档工具同步改画布；图像工具进入 PostgreSQL `tool_runs` 队列，由 Worker 调 Python 服务。前一步失败阻断后续，轮次进入失败状态；用户可重试失败步骤。
6. 取消未开始步骤；排队任务直接取消，运行中任务在 Worker 检查点响应取消并丢弃后续结果。终态上的重复确认、取消或重试返回 409。
7. 每轮规划轨迹记录模型、耗时、token、工具提议和拒绝原因；需要通过授权接口查询，不能暴露密钥。

## 3. 工具、图层与选区

- 当前 `ToolRegistry` 共 22 个工具。9 个文档工具只改变画布文档；调色、去背景、投放尺寸等可由本地图像服务处理；9 个模型工具依赖 DashScope 图像接口，当前真实模型未启用。
- `GET /api/tools` 的 JSON Schema 与模型工具 Schema 由 Java 参数类型同源生成。前端工具面板不另写一套参数范围。
- 图层与选区是不同维度。`layer_id` 决定目标图层；选区决定局部区域。选区存 Redis，绑定会话修订号；修订号过期或缓存不可用时视为无选区。
- 笔刷生成实际遮罩；点选目前使用圆形区域近似，不能称为 SAM 语义分割。局部工具在计划校验后固定当前遮罩，避免确认前选区变化造成目标漂移。
- 拆层支持主体/背景；文字拆层需要 OCR，当前 `include_text=true` 明确报不支持。重复拆层、重复提升图层需避免多次生成同一结构。
- 结果去向由 Java 规则决定：编辑结果可替换当前画布；营销图、投放尺寸、多候选图优先进入图片墙，采纳后才更新画布。参数与去向细节见现有 `docs/architecture.md` §3.1。

## 4. 长任务和进度

- `tool_runs` 表是队列与状态权威。Worker 用租约与 `FOR UPDATE SKIP LOCKED` 领取；幂等任务在租约过期且未超次数时可重排，非幂等或次数用尽进入失败。
- 每个任务的输出只写入 `runs/{runId}/{attempt}/` 前缀；Java 校验前缀并登记素材。Redis Pub/Sub 只传进度通知；SSE 先读数据库快照，丢通知不丢终态。
- Python 只收 Java 给的对象键、参数、运行 ID、尝试次数和共享令牌；不能访问用户 JWT、改计划或独立持有业务状态。

## 5. 评测业务规则

- `agent-behavior-v1` 的 44 例与 MANIFEST 已冻结。真实 DeepSeek 与占位图像链路的能力声明必须准确。
- `confirm_gate`、`no_side_effect`、`confirm_flow`、`authz_isolation` 和 `regression` 是硬门；趋势指标报告分子、分母、跳过数、跨轮差异。
- 图像主观质量只在真实图像模型有输出且人工量表完成后评定。本阶段未启用 DashScope 图像模型，因此图像质量“未测”。
