# 天猫服饰类目首图规范

## rule-1 背景
背景必须为纯白或浅灰（#F5F5F5），不得使用花哨场景与渐变。

## rule-2 尺寸与比例
主图尺寸 800x800 像素起，长图按 3:4 比例提交。

## rule-3 文案
主图禁止出现促销、红包、二维码等文字元素。

## rule-4 主体占比
商品主体占比不低于 60%，不得大面积留白。

## rule-5 品牌标识
仅可出现自有品牌标识，位置固定在画面左上角，不得遮挡商品。

## rule-6 色彩还原
同款不同色需分别拍摄，不得用调色替代实拍。

## rule-7 模特
模特图需正面全身，不得使用虚拟模特替代实拍。

## rule-8 图片格式
提交 JPG 或 PNG，单图不超过 3MB，不得使用动图。
